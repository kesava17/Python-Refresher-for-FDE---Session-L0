## My work

### The question

> How might we give Sunrise's customers an instant, correct answer to their most common questions, without tying up an agent?

### Altitude check

- Too broad: "how might we fix support." (prompts nothing)
- Too narrow: "how might we build a chatbot." (answer pre-chosen)
- Right altitude: the question above. Specific outcome, specific user, real constraint, no tool.

### The options it invites

Asked at the right altitude, three genuinely different answers fall out:

| Option | One line |
| --- | --- |
| **Deflect** | Answer the customer directly, so no ticket is opened. |
| **Route** | Classify an incoming ticket and send it to the right queue. |
| **Assist** | Draft a reply for a human agent to review and send. |

Each satisfies the question; each is a different bet. The problem now has a real menu, not a foregone conclusion.
